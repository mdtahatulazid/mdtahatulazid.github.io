# Md. Tahatul Azid — multi-page portfolio

Nine static pages: Home, About, Fieldwork, Projects, Research, Experience, Gallery, Honours, Contact.

This edition combines the cinematic Fieldnotes design with the supplied detailed field-seasons timeline, original planning-studio content, recognition records and 64 additional source photographs. The Gallery has 69 interactive images. The case-study and publication filters, image viewer and mobile navigation all work without a backend.

**Publish for free:** Create a public GitHub repository named `YOUR-USERNAME.github.io`. Upload the extracted files and the `assets/` folder to the root of its `main` branch (not the ZIP itself). In **Settings → Pages**, set source to **Deploy from a branch**, branch **main**, folder **/(root)**. Your site becomes available at `https://YOUR-USERNAME.github.io/`.

The original CV and full portfolio PDFs were excluded from this public package because they contain private contact details; the website offers an email-based request instead.

The site uses plain HTML/CSS/JavaScript. No installation, build step or paid service is required. You can open `index.html` locally to review it before uploading. An internet connection is used only to load Google Fonts and any external research/social links.
